# Interview-IQ

## Overview
Interview-IQ is an AI-powered mock interview platform that helps users practice technical interviews with AI-generated questions and receive instant feedback.

## Features
- AI-generated interview questions
- Easy, Medium, Hard difficulty levels
- Technical interview practice
- Interactive dashboard

## Tech Stacks
- React
- Flask
- Python
- Ollama (Llama 3.2)
